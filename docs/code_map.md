# Карта кода

Проект разделён по исследовательским обязанностям, а не по этапам прошлых
экспериментов.

## `src/`

- `data.py` строит полную таблицу пар `(a, b)`, one-hot цели и два вида
  разбиения. `random` используется в основной серии, `symmetry_safe` оставлен
  как отдельный контроль переноса.
- `models.py` содержит две сравниваемые архитектуры. `GromovQuadraticNetwork`
  - bias-free двухслойная MLP; `SplineKAN` - два слоя, в которых каждое ребро
  является обучаемой суммой SiLU-ветви и B-spline.
- `train.py` выполняет full-batch обучение с MSE, сохраняет историю, финальную
  модель и точные состояния начала устойчивого запоминания и обобщения.
- `metrics.py` определяет пять взаимоисключающих классов динамики. Поле
  `phase_metrics.dynamics` является источником истины для всех таблиц.
- `analysis.py` содержит Fourier- и PCA-метрики, включая полный центрированный
  classwise-спектр, используемые одинаково для MLP и KAN.
- `study.py` реализует Wilson interval и единый безопасный экспорт CSV.
- `utils.py` отвечает за seed, конфигурации, устройство и версии среды.

## `scripts/`

- `run_experiment.py` запускает один конфиг и принимает каждый override через
  отдельный `--set`.
- `run_study.py` разворачивает `configs/final_study.yaml` в 80 запусков,
  возобновляет прерванную работу и ведёт полный manifest.
- `aggregate_study.py` строит парные таблицы и главную фазовую карту без
  фильтрации seed.
- `analyze_mechanisms.py` анализирует один сохранённый запуск.
- `analyze_mechanism_matrix.py` применяет одинаковый Fourier/PCA-протокол к
  десяти моделям, сохраняет таблицы частот и индивидуальные heatmap и
  агрегирует edge-ablation пяти KAN.
- `make_symmetry_control.py` собирает явную таблицу и график random против
  symmetry-safe режимов, сохраняя полные знаменатели и разные train fractions.
- `make_figures.py` создаёт диагностические кривые одного запуска.
- `audit_study.py` проверяет 80 запусков, взаимоисключающие фазы, Fourier-таблицы,
  контрольные графики и документы перед выпуском.
- `validate_release.py` проверяет структуру очищенного комплекта.
- `build_manifests.py` создаёт инвентарь результатов и SHA-256 суммы.

## Поток данных

`final_study.yaml` задаёт матрицу -> `run_study.py` сохраняет 80 независимых
папок -> `aggregate_study.py` читает только их `summary.json` и metadata ->
механистический скрипт читает десять заранее выбранных наборов весов -> отчёт и
презентация используют только финальные CSV и PNG.

Такое направление зависимостей не позволяет вручную исправить подпись фазы в
таблице, не изменив исходный `phase_metrics` конкретного запуска.
